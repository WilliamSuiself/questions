# 《三国演义》原著陷阱清单（新题必读）

> 下列内容在评书、戏曲、《三国志》、民间演绎里很常见，但**《三国演义》一百二十回正文里没有**，
> 或者说法与原著不同。**不能作为正确答案或题干前提。**

## 一、曹操的诗：原著一首都没收

《观沧海》《龟虽寿》《短歌行里的「对酒当歌」全篇》《蒿里行》——除《短歌行》外，**原著正文并不收录**。
原著里出现曹操诗作的只有：

- 第四十八回「对酒当歌，人生几何」——这是**曹操在建安四年Posts的《短歌行》**，是被引用的。
- 第五十六回《铜雀台赋》（赋，不是诗）
- 第四十八回曹操自叙「吾死之后，葬于邺之西门」等墓志铭式的交代
- 第五十四回曹操令曹丕作《铜雀台赋》

**写作提示**：要出「诗词原文」题，只能用「后人有诗」「正是」「有诗为证」等**书里明写的诗**，
以及《铜雀台赋》《出师表》《陈情表》《隆中对》这类正文收录的文。

## 二、著名「伪原著」表述

| 常见说法 | 原著实况 |
|---|---|
| 「羽扇纶巾，指挥若定」 | 原著**无「羽扇纶巾」四字连用**。孔明的装束是「头戴纶巾，身披鹤氅，手执羽扇」（第五十二回）、「纶巾羽扇，素衣皂绦」（第九十三回） |
| 「跨有荆益」 | 《三国志》措辞，原著没有 |
| 「奉天子以令不臣」 | 《三国志》措辞，原著没有。第十四回荀彧原话是「今天子蒙尘，将军诚因此时首倡义兵，奉天子以从众望，不世之略也」 |
| 「弃之可惜，食之无味」 | 评书版。原著第七十二回杨修解「鸡肋」是「**食之无肉，弃之有味**」 |
| 「马谡献计降姜维」 | 原著**无此事**。降姜维是第九十三回诸葛亮用反间计 |
| 「雌雄双股剑」 | 原著**只有「双股剑」**，无「雌雄」二字 |
| 「摔阿斗」 | 原著第四十回是「**掷**阿斗于地」 |
| 「温酒斩华雄」 | 原著第五回是关羽「出帐提华雄之头，掷于地上，**其酒尚温**」；「温酒斩华雄」是后世定名 |
| 「桃园三结义」 | 原著是「**宴桃园豪杰三结义**」，回目用「桃园」 |
| 「三英战吕布」 | 回目作「破关兵三英战吕布」 |
| 「关云长千里走单骑」 | 回目作「**美髯公**千里走单骑」（第二十七回） |
| 「孔明三气周公瑾」 | 回目作「孔明二气周公瑾」「孔明三气周公瑾」分散在第五十一、五十五、五十七回 |
| 「草船借箭」 | 回目作「用奇谋孔明借箭」，且是孔明向孙权「借」箭，不是偷 |
| 「空城计」 | 回目作「**武乡侯**四番用计」等，空城是第九十五回 |
| 「华容道义释曹操」 | 原著第五十回写「关公纵马提刀杀向曹操」，后文借「赤兔马被绊」等收场，**没有「义释」二字** |
| 「挟天子以令诸侯」 | 原著无此六字连用 |

## 三、其他要小心的点

- **曹昂**：第四十一回写他是曹操**妾室刘氏所生的长子**，妻丁夫人无出。
- **许劭评曹操**：原作「**治世之能臣，乱世之奸雄**」（第一章），不是「治世之能臣，乱世之奸雄」之外的「奸雄」变体。
- **关平**：原著第五十二回以前**未出现过**关羽义子关平之名，出场在第七十四回以后。
- **周瑜**：字公瑾（第十五回），「美周郎」是曹操语。
- **诸葛亮**：字孔明（第三十六回），号「卧龙」。
- **曹操**：字孟德（第一回），「曹孟德」在回目里大量出现。
- **孙权**：字仲谋（第十一回），曹操叹「生子当如孙仲谋」。
- **吕布**：字奉先（第三回），有「人中吕布，马中赤兔」。
- **张飞**：世居涿郡，**卖酒屠猪**（第一回），不是「燕人」。
- **赵云**：常山真定人（第七回），字子龙。
- **关羽**：字长生后改云长，**河东解良人**（第一回）。
- **马超**：字孟起，扶风茂陵人（第十回）。
- **郭嘉**：字奉孝（第十回）。
- **荀彧**：字文若（第十回）。
- **司马懿**：字仲达（第三十九回）。
- **庞统**：字士元（第四十七回），号凤雏。
- **太史慈**：字子义（第十一回）。
- **黄盖**：字公覆（第四十五回前后）。
- **陆逊**：字伯言（第八十回前后）。
- **吕蒙**：字子明。
- **严颜**：字「不」。原著是「张飞义释严颜」——「严颜字不」。
- **马谡**：字幼常（第八十回前后）。
- **姜维**：字伯约（第九十三回）。
- **邓艾**：字士载（第一百十一回）。
- **钟会**：字士季（第一百十一回前后）。
- **许攸**：字子远（第十回）。
- **审配**：字正南（第三十一回前后）。
- **田丰**：字元皓。
- **沮授**：字德珪。
- **孔融**：字文举（第二十三回）。
- **祢衡**：字正平（第二十三回）。
- **管辂**：字公明（第六十九回）。
- **左慈**：字元放。
- **华佗**：字元化（第五十回）。
- **张松**：字永年（第六十回）。
- **法正**：字孝直（第六十回）。
- **孟达**：字子度（第六十四回前后）。
- **马良**：字季常（第九回前后，荆州马氏五常）。
- **马谡、马岱**：马岱是马超从弟。
- **诸葛瞻**：字思远，诸葛恪是诸葛亮之兄诸葛瑾之子。
- **诸葛诞**：字公休（与文钦征东吴）。
- **辛宪英**：曹魏女，辛毗之女。

## 四、兵器名要照原著写

- 关羽：**青龙偃月刀**（又名冷艳锯，重八十二斤）、**双股剑**（与刘备各执一剑）、赤兔马。
- 张飞：**丈八蛇矛**（点钢矛）。
- 赵云：**青釭剑**（其上有「工造青釭剑」七字）、亮银枪。
- 马超：**虎头湛金枪**。
- 吕布：**方天画戟**、赤兔马。
- 黄忠：**凤嘴刀**、花翎箭。
- 诸葛武侯：**雌雄双股剑**？——**没有**，只有「双股剑」是刘备的。
- 黄月英：**木牛流马**（诸葛亮造）、连弩（一说）、「排山倒海」之具。
- 许褚：**古锭刀**（原文「古锭刀」，非「古定刀」）。
- 典韦：**双铁戟**。
- 关羽的「赤兔」在第5回是吕布的，后来归关羽。
- 诸葛亮的坐骑：**木鹿大王**（第七十七回）、「绝影」「的卢」非其坐骑。
- 刘备的马：**的卢**（第三十四回檀溪一跃）。

- 司马师字**子元**、司马昭字**子尚**（第九十四回）

- 曹髦字**彦士**（第一百零九回）、毌丘俭字**仲恭**（第一百一十回）

## 七、第二轮扩题时踩到的具体坑

- **《短歌行》**：整首确实收在第四十八回曹操横槊赋诗里，但题干必须写明「《三国演义》第四十八回」，
  否则就是在考曹操文集 —— 与《观沧海》《龟虽寿》《蒿里行》原著不收录是同一条纪律。
- **第六十七回「后人有诗」叹的是杨松**（卖主求荣被斩），不是张辽逍遥津；
  本回咏叹刘备孙权胜负的是另一首「的卢当日跳檀溪；又见吴侯败合淝」。
- **杨修解「鸡肋」原著原句**：「鸡肋者，食之无肉，弃之有味。今进不能胜，退恐人笑，在此无益，不如早归。」
  所以「弃之可惜，食之无味」是后世俗说，「弃之无味」是错字版，两者都不能当正确项。
- **第一百一十六回守南郑关的蜀将姓「卢」**（原文「守关蜀将卢逊」），不是东吴的陆逊。
- **钟会祭的是「诸葛武侯之墓」**：定军山并无神庙，原著借诸葛亮显圣吓退魏军。
